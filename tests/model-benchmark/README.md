# tests/model-benchmark

The permanent 75–100 prompt suite for choosing the v1 LLM (Phase 1). Covers normal and
casual conversation, natural profanity, each personality, roleplay, instruction following,
reasoning, structured JSON, tool-call formatting, memory-style questions, refusal tendency,
context retention, plus latency / RAM / tokens-per-second measurement.

**Placeholder until Phase 1.** Once created, these prompts are permanent — they are re-run
against future candidate models.
